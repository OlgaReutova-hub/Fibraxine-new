# Пример рациона со сниженной калорийностью

Интерактивный калькулятор рациона для пациентов на гипокалорийной диете. При изменении параметров меню, дефициты микронутриентов и памятка обновляются автоматически.

## Возможности

- Подбор типового меню на день по калорийности (1200 / 1500 / 1800 / 2000 ккал) и типу питания (офисное, домашнее, перекус в городе)
- Отображение дефицита пищевых волокон и железа (% от суточной нормы) с цветовым индикатором
- Автогенерация HTML-памятки для пациента с тремя вариантами меню на выбранную калорийность
- Скачивание памятки в виде HTML-файла

## Деплой

Статический сайт — Python и сервер не нужны. Достаточно загрузить файлы на любой хостинг:

```
index.html          ← всё приложение
data/
  Шаблон памятки.html
  fibra_section_bg.png
  упаковка.webp
```

Или подключить через **GitHub Pages**: Settings → Pages → Source: `master` / `/ (root)`.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Приложение (данные, логика и изображения встроены inline) |
| `data/Шаблон памятки.html` | HTML-шаблон с плейсхолдерами `{{...}}` |
| `data/fibra_section_bg.png` | Фоновое изображение памятки |
| `data/упаковка.webp` | Изображение упаковки Фибраксин |
